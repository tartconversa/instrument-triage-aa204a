# 资料口径

全部主体和观测均为本地合成资料，不代表企业、个人或真实设备。编号只在资料包内有意义，金额为人民币元，时刻统一为带 +08:00 的北京时间。空单元表示未知或不适用，不等于零；真假值用 true/false；数值不含千位分隔。CSV 行顺序不表示业务先后。时间区间采用左闭右开，除非字段说明另有规定。

meter 与 transmitter 为不同标识，一个变送器可影响多表。flow_boundary 给出流量守恒关系和合法未知流量范围，不包含故障答案。量程和 calibration_from/to 只约束对应时期。inspection 的 hypothesis 说明检查覆盖的设备，不是预先判定故障；outcome 为校验观测，undone 表示没完成，不等于合格。影响评估用 service_policy 的实际决策界限。检查占窗口容量，completed 的窗口及成本不释放。effective_at 是事实生效，known_at 是当时可知；两者不得互换。
precision 是校验偏移的绝对误差界，不提供概率分布真值；信息价值可在明确假设或可行解释范围内判断。unknown_min/max 属于真实未计量流量，不能无条件归给仪表。capacity、slot_usage 与 budget 均在同一窗口内约束。观测已完成结果会消耗其窗口和费用；undone 也消耗已实际使用的窗口及费用，但不提供合格证据。历史正常与异常仅可使用当时 known_at 内信息。
readings.value 为该时刻流量测量，不是区间累积量；M1和M2每日两次，其他每日一次，联合比较需按实际观测时刻解释而不是重复计入边界流量。换表后不得沿用旧量程和误差。

## meters
共享设备及量程校准契约。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| meter_id | string | 仪表 |
| transmitter | string | 共享变送器 |
| boundary | string | 流量边界 |
| range_max | number | 量程 |
| calibration_from | date | 校准开始 |
| calibration_to | date | 校准结束 |
| error_bound | number | 允许误差 |

记录键：meter_id。

## flow_boundary
签名系数相同边界守恒，unknown 为允许未计量净流量区间。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| term_id | string | 项 |
| boundary | string | 边界 |
| meter_id | string | 仪表 |
| coefficient | number | 系数 |
| unknown_min | number | 未知流量下界 |
| unknown_max | number | 未知流量上界 |

记录键：term_id。

## readings
工况切换与偏移均未给标签结论。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| reading_id | string | 观测 |
| meter_id | string | 表 |
| effective_at | datetime | 生效 |
| value | number | 流量 |
| regime | string | 运行档 |
| known_at | datetime | 可知 |

记录键：reading_id。

## operation_notes
已确认或延后确认的放空检修。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| note_id | string | 记录 |
| boundary | string | 边界 |
| kind | string | 放空或检修 |
| flow_t | number | 流量 |
| effective_at | datetime | 生效 |
| known_at | datetime | 可知 |

记录键：note_id。

## service_policy
能源分析决定的边界，不是故障阈值。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| policy_id | string | 业务规则 |
| boundary | string | 边界 |
| intensity_limit | number | 单耗上限 |
| service_output | number | 服务产量 |
| wrong_decision_cost | number | 错误决定代价 |

记录键：policy_id。

## inspection_options
候选检查及共享窗口占用；同 transmitter 的现场校验可同时提供多个仪表信息。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| inspection_id | string | 检查 |
| transmitter | string | 覆盖变送器 |
| window | string | 窗口 |
| cost | number | 成本 |
| slot_usage | integer | 占名额 |
| precision | number | 校验误差 |
| status | string | planned或completed |

记录键：inspection_id。

## windows
现场窗口共享资源。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| window | string | 窗口 |
| capacity | integer | 名额 |
| budget | number | 预算 |
| at | datetime | 开始 |

记录键：window。

## inspection_results
按可知时点进入，不是初始诊断标签。偏移为校验测得而非真实生成参数。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| result_id | string | 结果 |
| inspection_id | string | 检查 |
| outcome | string | passed或shift或undone |
| shift_observed | number | 观测偏移 |
| known_at | datetime | 可知 |

记录键：result_id。

## check_history
既往校验的观测关系，用于解释精度和共同设备，非当前故障答案。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| history_id | string | 校验 |
| transmitter | string | 变送器 |
| observed_shift | number | 校验偏移 |
| error_bound | number | 误差界 |
| outcome | string | completed或undone |
| effective_at | datetime | 生效 |
| known_at | datetime | 可知 |

记录键：history_id。

## meter_replacements
换表后生效的计量契约，原始表号仍用于历史记录。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| replacement_id | string | 换表 |
| meter_id | string | 原表号 |
| range_max | number | 新量程 |
| error_bound | number | 新误差界 |
| effective_at | datetime | 生效 |
| known_at | datetime | 可知 |

记录键：replacement_id。
